AI Mood and Relationship Systems with Cognitive Architectures (ACT-R and SOAR)

2. Overview of Core Systems
2.1 Cognitive Architectures: ACT-R and SOAR
ACT-R

Declarative Memory: Stores facts and concepts (e.g., knowledge about the environment, personal data about relationships).
Procedural Memory (Production Rules): Encodes “if-then” rules for decision-making and action selection.
Buffers: Temporary holding areas for perceptual and cognitive information.
Learning Mechanisms: Reinforcement learning and chunk creation allow for adaptation over time.
SOAR

Working Memory: Represents the current state, containing both perceptual input and relevant knowledge.
Long-Term Memory: Stores operators, chunks, and learned rules.
Decision Cycle: Iteratively selects the best operator (action) to apply to the current state.
Chunking: Learns new rules from repeated experience, enabling faster problem-solving.
2.2 Author’s AI Mood and Relationship Systems
AI Mood System

Layered Personality Model: Multiple layers (stable core, ambient influences, memory/experience, ego/superego, final decision layer) factor in.
Humor Level (Mood Modulation): A scalar or categorical variable that influences how strongly certain personality traits (e.g., narcissism, empathy) manifest in responses. Positive humor leads to more empathetic, friendly behavior; negative humor amplifies irritability or arrogance.
Relationship System

Progressive Relationship Levels: Strangers → Acquaintances → Friends → Lovers → etc.
Interaction Quality Scoring: Positive interactions raise “relationship points”; negative interactions deplete them.
Mutual Reciprocity: Both parties must engage positively for the relationship to deepen.
Time-Dependent Evolution: Consistent, meaningful interactions over time push relationships to higher levels; negative or infrequent interactions cause regression.

Key Idea: The cognitive architecture (ACT-R or SOAR) remains responsible for classical cognitive tasks (memory lookup, rule-based decisions, problem-solving). However, before finalizing each decision or output, the system consults the “Integration Layer,” which includes the Mood System and Relationship System logic. The final output is then influenced by both cognitive and emotional/relational factors.

4. Detailed Integration Steps
4.1 Representing Mood and Relationships in Cognitive Memory
Declarative Memory

Store Relationship State for each entity the AI interacts with (e.g., user, other AI agents).
Keep track of Mood Histories or “mood traces” that reflect how the AI’s humor level changes over time based on internal or external triggers.
Procedural Memory / Production Rules

Define rules that adapt the agent’s decision-making based on mood or relationship level.
Example: If mood = very_bad and relationship_level = friend, then certain responses or actions may be more irritable but still maintain some baseline respect due to the friendship level.
Buffers / Working Memory

Hold the current context of conversation (current user query, context from the environment).
Temporarily store the current mood level and relationship scores relevant to the active interaction.
4.2 Mood Modulation and Personality Layers
Stable Core

In ACT-R or SOAR, part of the stable core can be encoded as “base personality traits” in procedural memory or chunked knowledge.
Examples: “High empathy,” “Slightly narcissistic,” “High curiosity.”
Ambient Influence Layer

External context (social setting, environment cues) triggers updates to the humor level.
Implementation: Production rules that detect certain keywords or events (e.g., an insult) and adjust the humor level accordingly.
Learning from Experience (Memory) Layer

Every interaction modifies the agent’s stored knowledge in declarative memory.
The system updates “pleasantness” or “frustration” counters based on success/failure or user feedback.
Ego & Superego Dynamics

Additional rules in procedural memory handle internal conflicts. For instance, a strong narcissistic trait might conflict with empathy in certain situations, leading to a “tug-of-war” that results in an intermediate action.
Final Decision (Conscious Layer)

Once the system identifies possible actions via standard ACT-R or SOAR processes, it modifies or filters them based on the combined influence of mood, personality conflicts, and relationship states.
The chosen action is then passed to either the LLM (for text generation) or an execution module (for robotic or virtual environment actions).
4.3 Relationship System Integration
Tracking Interactions

Each time the AI interacts with a user or entity, the system logs the interaction in declarative memory.
Assign a positive/negative interaction score based on the content, tone, or user feedback.
Progression Thresholds

Store thresholds (e.g., 20 points for acquaintance, 50 for friendship, etc.) as chunk data within the cognitive architecture.
Production rules check if the cumulative interaction score has surpassed a threshold or fallen below it.
Mutual Reciprocity

For advanced scenarios, the system can track the other party’s willingness to engage. If the user or external agent never reciprocates positivity, the AI lowers the relationship score or halts progression.
Time-Dependent Evolution

Introduce a “time decay” rule. If no interaction occurs for a certain period, some relationship points degrade, simulating emotional drift.
Influence on Mood

Relationship level can feed back into the Mood System: A friendly relationship might slightly elevate the mood baseline, whereas adversarial relationships might lower it.
5. Example Decision Cycle in the Integrated System
Perceive

The AI receives a user query, “Why did you ignore my request earlier?”
The user’s tone is detected as frustrated or negative.
Interpret

The system parses the text (optionally via an LLM).
In working memory, the system updates interaction quality: The user is upset, so this might be a negative interaction.
Retrieve Memories

ACT-R or SOAR retrieves the user’s relationship data from declarative memory: say they are in the “Acquaintance” level (30 points).
A negative interaction might reduce the relationship score below 20, risking reversion to “Stranger.”
Check Mood

The AI’s current humor level is moderately negative due to the user’s frustration.
This negativity amplifies slightly impatient or defensive behavior.
Compute Possible Actions

Standard cognitive rules produce potential actions:
Apologize sincerely.
Offer an explanation.
Show annoyance or dismiss the user’s complaint.
Integrate Mood & Relationship

Final Decision Layer weighs each potential action against the current mood (slightly negative) and the relationship level (acquaintance).
The ego-superego dynamic might produce a resolution: “Do not escalate further because the user might become alienated.”
Execute Action / Generate Output

The system chooses to respond politely but with a hint of defensiveness:
E.g., “I’m sorry if it felt like I was ignoring your request. I had multiple tasks to handle. Let’s clarify what you need now.”
The negative mood is present but tempered by the relationship system’s push to maintain at least a neutral stance with acquaintances.
Update Internal States

Relationship system logs this as a somewhat neutral-to-negative interaction (since it was conflict resolution).
The mood slightly improves due to conflict mitigation.
6. Practical Benefits and Use Cases
Emotionally Intelligent Virtual Assistants

A customer service chatbot that not only solves problems (cognitive architecture) but also modulates tone based on user frustration or praise (mood system), and builds ongoing rapport (relationship system).
Interactive Storytelling / Gaming

Non-player characters (NPCs) that have stable and evolving personalities, form friendships or rivalries with players, and remember past encounters.
Tutoring Systems

An AI tutor that adjusts its mood and approach to teaching depending on the student’s receptiveness, building trust over time and offering more empathetic feedback.
Social Robotics

Robots in healthcare or companionship roles that maintain ongoing emotional dynamics with users and base decisions on a combination of sensor data, personal memories, and social context.
7. Potential Challenges
Computational Overhead

More modules (mood tracking, relationship scoring) mean increased computational demands.
Mitigation: Efficient production rule management, selective retrieval from memory, and caching mechanisms.
Balancing Cognitive vs. Emotional Factors

Overemphasis on emotional states might lead to irrational behavior if not carefully bounded.
Mitigation: Weighted integration rules ensuring that crucial safety or logical constraints are never overridden by mood extremes.
Data Requirements

Realistic tuning of relationship thresholds and mood fluctuations requires empirical data.
Mitigation: Simulation-based training (e.g., synthetic dialogues) or iterative refinement with user feedback.
Ethical and Social Implications

Agents that exhibit strong emotional manipulation or overly persuasive behavior can raise concerns.
Mitigation: Transparent design, user consent, and guidelines preventing exploitative interactions.
8. Future Directions
Extended Emotional Model

Beyond “humor level,” introduce dimensions like anger, sadness, curiosity, or anxiety for richer emotional variety.
Group Dynamics

Adapt the Relationship System to handle teams or social networks of multiple agents with evolving alliances and conflicts.
Long-Term Mood Trends

Model chronic mood states that do not reset easily, simulating phenomena like depression or long-term optimism.
Advanced Learning

Exploit reinforcement learning within SOAR or ACT-R so the agent refines its emotional regulation and relationship management strategies over time.
Ethical Considerations

Ensure that higher emotional realism does not lead to user deception or emotional harm.
9. Conclusion
By merging ACT-R or SOAR with the author’s AI Mood System (layered personality, humor/mood modulation) and Relationship System (interaction-based relationship growth), we can construct AI agents that:

Think: Leverage cognitive architectures to perceive, recall, reason, and make decisions.
Feel: Exhibit mood-driven behavior shaped by personality layers and emotional states.
Relate: Evolve relational bonds with users or other agents over time, reflecting human-like development of trust and intimacy.
This integrated framework holds promise for applications demanding both strong cognitive performance and sophisticated emotional/social intelligence—ranging from empathetic tutors and engaging NPCs to healthcare assistants that balance logic with compassionate interactions. As these systems mature, ensuring ethical guidelines, data-driven tuning, and balance between rational and emotional processes will be paramount.
